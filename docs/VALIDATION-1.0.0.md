# Waylore 1.0.0 发布检查

日期：2026年10月28日。当前客户端在 `mobile/`；Windows、安卓手机及安卓平板对外版本均为1.0.0。

## Android

- 内部构建45，包名 `com.changanhe.kexinglu`，最低Android 7 / API 24。
- 包含 armeabi-v7a、arm64-v8a、x86_64；沿用上一版正式签名。
- 静态分析无问题；142项自动化测试通过、4项跳过。
- 安卓模拟器运行正式APK，检查2560×1600横屏与1600×2560竖屏；首页双栏、旅途地图、手帐侧边工具栏、素材添加、保存及应用内隐私政策均完成运行检查。
- 选曲自动播放，退出手帐停止，再打开恢复对应曲目；通过播放器界面及系统AudioTrack启动事件核对。
- APK SHA-256：`e9fd028b925cf50aeb918676a00caaf8f71042cb2c9092e952d977e6a30c82db`。

## Windows

- 与安卓共用Dart界面；Windows x64发布构建，附带Visual C++运行库。
- [Windows构建与验证](https://github.com/changanhe/Waylore/actions/runs/40697328766)：静态分析、测试、原生编译、SQLite初始化、保持运行和重复打开复用窗口通过。
- 安装程序与便携包通过SHA-256核验后附加至发布草稿。安装程序注册登录回调，便携版未注册回调时使用邮箱密码登录。
- 本机使用隔离临时数据验证启动、URL回调激活已有窗口及窗口缩放；已检查实际桌面截图。
- 旧版SQLite导入测试验证记录转换、重复跳过、缺失照片处理与源文件不变；未修改用户的实际旧数据库。

## 范围

模拟器与自动化验证不能代表所有真机的驱动、权限、照片选择器和系统分享行为。未执行真实第三方账号授权或跨设备云同步验收；这些功能依赖相应服务端配置。未提供原生鸿蒙、macOS、Linux或iPad安装包。
