# 安卓节日体验版 · 1.0.0

本轮仅保存在本地，未提交 GitHub、未上传网站。

体验入口：
- 首页问候旁的“节日祝福”。
- 我的 → 设置 → 节日与祝福。
- 点击任意节日，立即预览完整开屏，不需要改手机日期。

展示规则：
- 原生日开屏与首页彩带完整保留，生日优先。生日开屏当天每次启动出现，彩带按原规则当天一次。
- 节日开屏默认每个本地账号每天一次，约 3 秒，可立即跳过。生日当天不再叠加节日开屏。
- 节日手册的预览不改变生日资料、系统日期或自动展示次数。
- 普通日子不开节日开屏，首页提供每日寄语。
- 可单独关闭节日开屏或国际/文化节日，不关闭生日祝福。
- 遵循“减少动效”设置。清明、国家公祭日与和平主题采用安静画面。

日期与范围：
- 精选中国传统节日和常见国际/文化节日，并非覆盖全球每个国家的全部节日。
- 春节、除夕、元宵、龙抬头、端午、七夕、中秋、重阳、腊八按农历计算，闰月不重复庆祝。
- 清明、立春、冬至按节气计算；母亲节、父亲节、美国感恩节、复活节（西方）按各自规则计算。
- 农历与节气计算使用 lunar 1.7.8（MIT），本版使用范围 1901–2100。不需要节日接口、定位权限或在线请求。
- 根据设备本地年月日显示祝福，不将节日文化问候当作各国法定休假或中国调休安排。
