# 客行录安卓 1.0.0 · 界面与翻页更新

内部构建号 44。仅交付本地安装包；未更新 GitHub 和网站。请覆盖安装，不要先卸载旧版。

## 体验路径

- 首页：日期下方的「每日寄语」每天更新；点击可查看完整寄语、摘录和节日设置。生日当天优先显示生日祝福，原生日开屏与彩带保留。
- 我的 → 关于：仅保留隐私政策、联系与支持两个服务入口。隐私政策在应用内新页面打开，内容随安装包离线提供，可以滚动和选择复制文字。
- 旅行手帐：页码旁点击翻页效果，选择平滑、折页、书页或淡入。选择会保存在本机，重新打开仍沿用。
- 横屏：开启手机系统自动旋转后横置手机。编辑工具自动移到右侧并换行排列，唱片避开工具区，左侧纸页可以上下浏览；阅读模式左右翻页。编辑时使用页码两侧箭头翻页，以免与素材拖动冲突。
- 原来的悬浮唱片、十二首配乐、MP3 导入、自动播放、背景和字体选择继续使用。
- 开启「减少动态效果」或系统减少动画时，关闭装饰性翻页变形。已有记录无需迁移。

## 设计依据

参考公开产品页面的内容组织与阅读层次，没有复制其图片、图标或界面代码：

- [Day One](https://dayoneapp.com/)：以记录内容为中心的阅读界面。
- [Polarsteps](https://www.polarsteps.com/)：照片、旅程和实体旅行册的呈现关系。
- [Journey](https://journey.cloud/)：媒体、地图与记录的清楚分工。

本次采用纸白底色、低饱和绿色、细边界和统一标题，移除首页铺满背景，缩减重复卡片装饰。原有五项导航、票夹、主题和个人背景功能保留。首页快捷入口使用两列以照顾窄屏中文可读性。

视觉概念使用内置 image_gen（非 CLI），提示词方向：完整中文首页、手帐与隐私阅读页；私人旅行册风格；纸白、炭灰、森林绿；每日寄语在日期下方；紧凑记录入口；折页、悬浮唱片与横屏侧栏；减少装饰性英文、光晕、厚重阴影和无关统计。概念只作为视觉参考，生成图中的示意照片和隐私文案不作为产品内容。

隐私内容依据实际安卓代码编写，并核对 [Supabase 隐私说明](https://supabase.com/privacy) 和 [Open-Meteo 服务说明](https://open-meteo.com/en/terms)。应用内如实说明启动时账号服务检查、天气刷新、可选同步、音乐仅本机保存以及删除与注销的区别。
